Magnusim 0.3.0

Install and run as before: Setup.bat, then run.bat (see START-HERE.txt).
The Airfoil plugin ships off: turn it on in Settings -> Plugins, then click
Install dependencies (it downloads its own packages, about 200 MB, once).

What changed since 0.2.0

Plugins
- Magnusim is now built from plugins. Settings -> Plugins lists them: turn one
  on or off, reload them, and install a plugin's own Python packages.
- Incompressible Flow, the solver you used in 0.2.0, is now a bundled plugin
  (version 1.0.0). Existing projects open as before.
- Two new bundled plugins ship with this release:
  - Magnusim CAD 0.1.0 (on; Settings -> Plugins turns it off):
    - Design parts inside a project. Click "Design a part" on an empty
      project, "New design" on Home, or the CAD button in the project header.
    - Sketch with dimensions and constraints, then Extrude, Revolve, Sweep or
      Loft. Fillet, Chamfer, Shell, Combine, Split, patterns and mirrors,
      reference planes, axes and points, and named parameters.
    - Open a STEP file and edit it directly: Press-pull flat and curved faces,
      delete faces, split, combine, and export STEP.
    - Edit in CAD: right-click a STEP, IGES or BREP part imported in a
      simulation (in the tree, on the part in the view, or in its Geometry
      panel) to open it in CAD. Back with a change updates that geometry in
      place and keeps its boundary conditions; the original file is kept.
      A part whose geometry you removed asks before adding it back.
    - Sketching: draw construction geometry with X, click-and-drag to draw,
      drag a fillet's arrow to set its radius, a compact Sketch panel, the
      design tree in a rail while you sketch, sketch cursors and round points,
      and relations shown for what you select (Shift+R shows them all).
    - Banana for scale: a banana beside the part, or true-size in a sketch.
    - For CFD: Enclosure wraps the part in a box or cylinder of air; Combine
      Cut makes the fluid volume.
    - Leave CAD and you are back in the simulation with the part as the
      project's geometry. Boundary conditions follow the faces by name, and
      meshes are marked out of date.
    - What it does and its known limitations:
      magnusim-web/bundled-plugins/cad/README.md.
  - Airfoil 0.1.0 (off until you turn it on, see above). A 2D section from a
    NACA 4- or 5-digit code, its dimensions, or a .dat file; lift, drag and
    moment polars from NeuralFoil (instant), XFOIL (Windows) or an OpenFOAM
    2D solve in the app's WSL.
- Plugins can be updated on their own: Settings -> Plugins -> "Install plugin
  from zip..." installs a plugin, or a newer version of one, from a zip. It
  says what it installs and what running work it stops, and installs only
  after Install. A newer copy of a plugin that ships with Magnusim is used in
  its place ("Remove update" goes back); one that fails to load is taken away
  again and the previous version kept.
- Plugin authors: docs/plugins (GUIDE, API, authoring) and npm run plugin:new
  / plugin:check / plugin:pack (makes the zip). The plugin API is version 1.7.

Incompressible Flow
- Turbulence: Spalart-Allmaras and realizable k-epsilon join k-omega SST,
  k-epsilon, LRR, SSG and laminar.
- Boundary conditions: symmetry, freestream, total-pressure inlet, moving and
  rotating walls, and inlets or pressures that change with time in transient
  runs.
- Results: forces and force coefficients, point probes, the pressure
  coefficient, y+, wall shear stress, total pressure, vorticity and Q at every
  saved time. Plot Over Path, Iso Surface and Iso Volume have their own
  toolbar buttons. Export a run to ParaView (VTK) or open its case folder.
- Runs say when they converged and can stop once a monitor settles; a finished
  or stopped run can be continued from its latest result; Cores (Auto or a
  number) per run; starting-flow options including a potential-flow start;
  Numerics presets and SIMPLEC; an "Average from" time for transient runs.
- The Run panel says when a mesh is out of date before Start.

Meshing
- A face two bodies share is meshed through (it is inside the fluid), and a
  boundary condition cannot be put on it.
- Each mesher's panel shows only the settings it uses, with its own stage
  names and summary.
- Faster: pressure scaling fix, binary result fields, faster reconstruct and
  a much faster hex core.
- Standard meshes parts whose surface healing opened a gap, refines around
  small features by itself (so parts with small features get more cells),
  and sizes automatic boundary layers by the local cells.
- A mesh that fails says so in the Mesh panel, with a reason, also after a
  reload, instead of meshing forever.

Geometry and view
- Hide and show bodies of a multi-body part: right-click a body in the view
  or in the setup tree (one or several; hidden rows are grey).
- Hiding a face of a big part no longer freezes the view.
- A part removed and added again under the same name gets its own
  thumbnail; removing a geometry takes its studies out of the open tab, and
  removing the last one leaves the workbench empty.

Reliability
- Finished meshes and solves no longer leave their WSL copies behind; old
  ones are cleaned up on the next start.
- Deleted studies and geometries stay deleted; the setup tree updates at once.
- A run is no longer marked failed the moment it starts while the PC is busy.
- run.bat keeps the app on the code it started with; stop.bat ends only this
  folder's app.

Known limits
- On Standard (mostly tetrahedral) meshes the solver's gradient scheme
  over-predicts a laminar pipe's pressure drop by about 16 % (as in 0.2.0).
  A more accurate scheme is planned for the next version.
- Airfoil's XFOIL engine runs on Windows only.
- Standard meshes of some complex parts can still have very skewed cells
  (non-orthogonality up to about 84 degrees at fineness 5); they solve, but
  check the mesh quality summary.
- CAD: big STEP imports need 1-2 GB of browser memory; the rest of its
  known limitations are in magnusim-web/bundled-plugins/cad/README.md.


Magnusim 0.2.0 (previous release)

What changed since 0.1.0

- Panels rebuilt to match the 0.1.0 look: Mesh (fineness slider, Generate,
  progress and timers), Boundary conditions (pick a type, then Add, then click
  faces), Materials (click the body in the viewport), Run (Start with the reason
  it cannot start yet, live residuals).
- Settings (was Preferences) opens the Setup wizard, with a Plugins step.
- Turbulence models: all five run. Energy and passive species were removed
  (they were never read by the solver).
- Geometry: every format in the Add geometry picker imports and meshes (STEP,
  STP, IGES, IGS, BREP, BRP, STL, OBJ, PLY).
- STL / OBJ / PLY:
  - much faster to load (a 118k-triangle STL in about 10 s);
  - grouped into real faces (the vortex part has about 10 selectable faces,
    not one per triangle);
  - mesh cleanly with the Standard mesher (checkMesh passes; an STL solve
    matches the STEP result).
- Hex-dominant (snappyHexMesh) works from the app and keeps your boundary
  conditions.
- Meshes queue across projects: start a mesh while another project is
  meshing and it runs when that one finishes. The Queue button in the top
  bar (next to Settings) shows what is running and what waits; drag to
  reorder, x to remove. A waiting mesh says Queued, not the other mesh's
  timer.
- Several geometries in one project: clicking a geometry shows it with its own
  simulation (or none yet) in a fraction of a second, keeping the view when
  both fill about the same space; an open editor or face pick never carries
  over to the other one. Create Simulation -> Start from a study on the other
  geometry copies its settings, and its BCs, monitors and refinements land on
  the faces that are the same surface there; any face without a match is
  listed so you can pick it again. Its mesh and results stay with its own
  geometry. Compare shows which geometry each side is, and with Sync filters
  on, the other side draws the same cutting planes and coloring, with its
  particle trace seeded from its own matching faces (it says so if a seed face
  has no match there).
- uninstall.bat removes the Magnusim folder and the solver folders its
  projects used inside Ubuntu (other folders there are kept). It offers to
  remove Node.js, Python or Ubuntu only if this Setup installed them, each
  after its own typed confirmation; otherwise they are kept.

- Inflate boundary layer refinements on flat faces (a wall, an inlet end) now
  mesh; they used to hang for 8 minutes or crash the mesher. Round faces
  (holes, pipes) keep their exact layer thickness.
- A steady run with fewer iterations than its write interval now saves its
  last iteration instead of failing with no results.
- cfMesh meshes before any inlet/outlet boundary condition is set.
- Mesh 'Copy from another mesh' works from a mesh in another simulation or on
  another geometry (it used to say 'Copied' and copy nothing).
- Removing a geometry says that its simulations are removed with it (they
  are).
- stop.bat stops only its own Magnusim; it used to stop every copy running on
  the PC.

Things worth trying

1. New project -> Add geometry -> an STL. Pick the unit, and check that the
   faces are whole surfaces (click one).
2. Create Simulation -> add two Pressure BCs on the ports -> Materials + ->
   click the body -> Mesh -> Generate -> Run 1 -> Start.
3. The same with Mesh -> Advanced -> engine Hex-dominant.
4. One project, two geometries (for example the round-hole and teardrop-hole
   plates): set up the first, click the second, Create Simulation -> Start
   from the first -> Copy settings. Mesh and run both, open one run's
   Results, then Compare and pick the other.
