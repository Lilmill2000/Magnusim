Third-party code inside Open CASCADE Technology 7.9.3, as linked into
workspace/kernel/mk32.wasm

Open CASCADE Technology (OCCT) is LGPL-2.1 with the Open CASCADE exception
(OCCT-LGPL-2.1.txt, OCCT-LGPL-EXCEPTION.txt). A few of its source files carry
code under other permissive licences. The OCCT toolkits the kernel links
(kernel-build/build-occt.sh) include the four below; their notices are
reproduced here as their licences ask. The file paths are those of the OCCT
source at tag V7_9_3 (kernel-build/SOURCES.md).

OCCT is built without FreeType, FreeImage, TBB, RapidJSON, Draco, VTK, OpenGL,
OpenVR or FFmpeg, so none of those is in the kernel. OCCT's embedded DejaVu
fallback font (src/Font/Font_DejavuSans_Latin_woff.pxx) is not in the kernel
either.
